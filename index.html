使用场景

跨境办公与协作

访问海外文档、代码仓库、会议与企业邮箱时，选择延迟更低的区域节点。团队版可按部门拆分设备额度，并用定制路由把办公域名走指定出口。

流媒体与内容站点

基础版覆盖常见平台的基础解锁；旗舰版强调全节点原生解锁，减少地区检测失败。播放前切换至对应区域节点，并避免同时开启系统代理与浏览器插件造成规则冲突。

游戏加速

旗舰版含 IPLC 专线游戏加速优化，适合对丢包与抖动敏感的对战与登录场景。建议游戏进程走游戏节点，其余流量走规则分流，避免把下载占满游戏通道。

学术与公开资料检索

期刊、预印本与公开数据集站点可通过规则分流。长连接任务优先选用稳定中转，而不是单纯追求最低延迟的高峰节点。

配置流程

UU 强调可复现的配置流程。按下列顺序操作，可减少“已下载却连不上”的常见问题。每一步完成后无需刷新页面，直接进入下一步即可。

  1. 确认套餐与设备数。 对照同时在线上限。笔记本、手机、平板各计一台。超出后新连接会被拒绝，旧连接不受影响。
  2. 在 UU 官网完成订阅。 开通后进入用户中心复制订阅链接。链接属于个人凭证，不要发到公开群组或截图传播。
  3. 下载对应客户端。 Windows 与 macOS 建议 Clash Meta 内核客户端；Android 可用兼容 Clash 的应用；iOS 使用可导入订阅的商店客户端。详见客户端下载。
  4. 导入订阅。 在客户端选择“从 URL 更新/导入订阅”，粘贴链接并更新节点列表。首次导入需允许本地代理权限与通知（用于节点切换提示）。
  5. 选择规则模式。 日常使用推荐规则分流：国内直连、跨境走代理。需要全局时再切换，避免把系统更新与局域网打印也送入代理。
  6. 指定节点并测试。 办公选邻近区域；流媒体选目标平台所在区域；游戏选 IPLC 或低丢包专线。用客户端内延迟测试，不要只看名称里的国家标签。
  7. 锁定系统代理。 确认系统或浏览器已接管。若浏览器装了其他代理扩展，请关闭以免双重代理。完成后访问目标站点验证。

配置完成后，将订阅自动更新间隔设为 12 或 24 小时，以便节点变更同步。更换套餐后旧链接通常仍可用，若失效则在官网重新复制。

Windows 与 macOS：安装后打开客户端，进入 Profiles 或订阅页，粘贴官网提供的订阅地址并更新。首次启动若提示安装网卡或助手组件，请允许，否则系统代理无法生效。官方下载入口见本站下载专区说明，请只从 UU 官网获取安装指引，避免第三方修改包。

移动端

Android：安装兼容 Clash 的客户端，导入订阅后开启分应用代理，可仅对浏览器与指定 App 加速。iOS：在客户端中新增订阅，开启 VPN 配置描述文件。同一 UU 账号受套餐设备数限制，手机与电脑同时在线会计入额度。

订阅与节点

UU 机场节点包含普通线路池、原生流媒体节点及旗舰/团队的 IPLC 与高带宽 VIP 节点。名称中的区域为出口大致位置。连接失败时先更新订阅，再更换同区域其他节点，最后检查本地防火墙是否拦截核心进程。

线路与使用建议

日常浏览使用规则模式即可。大文件下载会快速消耗月度流量，建议避开高峰或使用团队版高带宽节点。游戏请固定一条延迟稳定的专线，频繁切换会导致重连。UU VPN 加速不替代杀毒与账号安全，请仍使用官方应用登录重要服务。

常见问题

UU 是机场还是 VPN？和官网下载有什么关系？

UU 同时提供机场订阅（可用于 Clash 等客户端）与 VPN 式系统代理能力。对本页而言，UU 机场、UU VPN 均指向同一官方服务。客户端下载请走 UU 官网指引，导入订阅后即可加速，不必再寻找来路不明的安装包。

如何完成从开通到连上的配置流程？

按本页“配置流程”七步执行：确认套餐与设备数、复制订阅、下载客户端、导入 URL、选择规则模式、指定节点、开启系统代理。任一步跳过都可能导致“有节点但浏览器不走代理”。导入成功后应能看到节点列表而非空白配置。

基础版、旗舰版和团队版该怎么选？

单人轻度使用选基础版（100GB / 3 设备）。需要原生流媒体、游戏 IPLC 与优先工单选旗舰版（300GB / 5 设备）。多人共用或需要定制路由、专属客户经理选团队版（1000GB / 20 设备）。年付价格按 10 个月计算。

官方客户端下载支持哪些系统？订阅能给第三方客户端用吗？

桌面支持 Windows 与 macOS，移动支持 Android 与 iOS 上可导入订阅的客户端，Linux 可用兼容核心。UU 订阅为通用链接，可导入 Clash Meta、Shadowrocket 等支持该格式的软件。请勿把链接填入未知在线转换网站。

流量如何计算？看视频和玩游戏会不会很快用完？

月度流量按代理出口统计，直连国内站点通常不计或占极少。高清流媒体与游戏更新最耗流量。基础版 100GB 适合日常网页与轻度视频；长时间 4K 或频繁更新建议旗舰或团队版。用量可在官网用户中心查看。

连接失败或流媒体仍显示地区限制时怎么处理？

先更新订阅并更换同区域节点；关闭浏览器内其他代理扩展；检查是否开启规则模式却把目标域名直连。流媒体请换用旗舰版全节点原生解锁线路，并清掉站点本地缓存后重试。若仅某个 App 失败，为该 App 单独指定代理。

设备数超限会怎样？团队如何共用？

超过同时在线上限时，新设备无法建立隧道，已连接设备保持。团队版支持 20 台在线，可通过定制路由把不同网段或域名分到不同出口。不要把同一订阅无限制发给外部人员，以免额度被占满。
